# Git & GitHub Workshop

## Git Commands

### git init
Creates a new local git repository.

### git branch -M main
Renames the current branch to main.

### New-Item README.md
Creates a new README.md file.

### git add README.md
Adds the README file to Git.

### git commit
Saves the changes in Git.

### git remote add origin
Connects the project to GitHub.

### git remote -v
Shows the GitHub connection.

### git push -u origin main
Sends the project to GitHub.
